## Compte rendu (rempli par l'agent)
**Fait** (fichiers : `firmware/src/{nvm,log}.rs` créés ; `tasks/{comms_rx,telemetry}.rs` complétés ; `lib.rs` : `pub mod log; pub mod nvm;` seulement). Rien sacrifié (NVM, anti-rejeu, Reboot, PowerCycle, ClearFdir, DumpEvents, journal : tout fait).
- **NVM** (`nvm.rs`) : bloc 16 o = `0xAE, 1, boot_count u16, last_tc_seq u32, plafond u8, isolées u8, short_boots u8, 0, CRC-32 (o. 0..12)`, 3 copies à 0x00/0x50/0xA0. Relecture : 1re copie valide (magic+format+CRC), champs **bornés** (plafond hors domaine → Nominal, isolées & 0b101, short_boots ≤ 15), `boot_count+1` saturant, réécriture+relecture de vérification des 3 copies (= réparation, `CNT_NVM_REPAIR`). Aucune valide → défauts + `FDIR_FLAG_NVM_LOST` + événement. **Choix à arbitrer** : NVM vierge (tout 0xFF, 1er boot de chaque run du sim) → défauts SANS `NVM_LOST` (événement `NVM_FORMAT`). Échec d'écriture (HalError ou relecture ≠) → `NVM_PENDING`, `CNT_NVM_WERR`, nouvel essai à chaque cycle par `nvm::service` (début de `comms_rx`) ; jamais de panique.
- **Signatures** : `pub fn boot_load<H: Hal>(ram: &mut Ram, hal: &mut H)` (idempotente dans un boot, bit `STATUS_LOADED` de `NVM_STATUS`) ; `pub fn save<H: Hal>(ram, hal) -> bool` ; `pub fn request_save(ram: &mut Ram)` ; `pub fn service<H: Hal>(ram, hal) -> bool` ; `pub fn pending(ram) -> bool` ; `log::push(ram: &mut Ram, code: u8, a: u8, b: u16)`.
- **Câblage pour le manager** : dans `sched::boot`, `boot_erase(ram, hal); nvm::boot_load(ram, hal); boot_finish(ram, hal);` (ordre déjà prévu par T-012 ; mes tests utilisent exactement cet ordre via `nvm::testkit::boot_full`, qui reste juste après câblage).
- **TC** : anti-rejeu saturant inchangé (`in_window`) ; à l'acceptation `LAST_TC_SEQ` (TMR) puis `nvm::save` AVANT exécution (testé : 1res écritures = nouveau SEQ + ancien plafond, toutes avant l'ACK). Si la NVM échoue, TC exécutée quand même, nouvel essai. `Reboot` : `REBOOT_PENDING=3` ; `telemetry` émet l'ACK puis `sys_reset` (attend au plus 3 cycles une NVM à jour, puis reset quand même). `PowerCycle` → `mode::start_power_cycle` (T-012). `ClearFdir` → `crate::tasks::fdir::clear_fdir(ram)` (existait déjà) puis `nvm::save`. `DumpEvents` → `log::start_dump`.
- **Journal / trames EVENTS** (doc complète en tête de `log.rs`) : anneau 40 × 8 o en SECDED ; entrée = `t u32 (uptime s), code u8, a u8, b u16` ; charge EVENTS = `log_total u16, left u8 (restant après cette trame), n u8 (0..=5), n entrées` ; une trame par cycle, la plus ancienne d'abord ; journal vide → 1 trame `n=0`. Codes : 0x01 BOOT, 0x02 NVM_LOST, 0x03 NVM_REPAIRED, 0x04 NVM_WRITE_ERR, 0x05 NVM_FORMAT, 0x10 TC_EXEC, 0x11 CEILING_SET, 0x12 REBOOT_CMD, 0x13 POWER_CYCLE, 0x15 CLEAR_FDIR, 0x16 REBOOT_RESET, 0xEE CORRUPT (entrée en erreur double, invalidée) ; 0x20..0x3F réservés FDIR. `log::decode_events` disponible pour le sol.
